# Northstar Broadcast Network

Northstar Broadcast Network is fictional. The two root JSON files are preserved, byte-for-byte legacy Milestone 0 fixtures. They prove the frozen same-source/different-destination intent, but they are not executable post-R2 destination profiles and do not claim the admitted requirement schema.

- `broadcast_master.json` — legacy strict broadcast-master fixture.
- `digital_preview.json` — legacy lighter digital-preview fixture.
- `legacy_m0/` — status and immutable-hash record for those root files.
- `source/` — reserved handoff for source specification documents at M2.
- `profiles/` — reserved handoff for admitted executable profile artifacts at M2/M3.

R2 creates only these contracts and markers. It does not generate synthetic media, execute evaluations, or populate final Northstar profiles.
